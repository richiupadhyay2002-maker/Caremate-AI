# Demo / Sample Files — Source & License Information

All sample files in `samples/` are **synthetic demo documents**. They contain
**no real patient information** and must never be presented as actual patient
records. They are provided for demonstrating and testing the CareMate AI
platform only.

## Format inspiration (open / public sources)

- **Synthea** — synthetic patient generator, MIT license:
  https://github.com/synthetichealth/synthea
- **MedlinePlus** (U.S. National Library of Medicine) — public domain
  patient-education content: https://medlineplus.gov/
- **National Cancer Institute (NCI)** — public domain cancer education
  material: https://www.cancer.gov/

## Authorship

The text of each sample file is **original content written for this project**,
styled after the open formats above. No text was copied from patient records
or copyrighted reports.
